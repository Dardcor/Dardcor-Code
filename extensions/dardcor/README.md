# Dardcor Code

Dardcor Code is a fast, lightweight, and extensible code editor powered by local and remote AI models through **Dardcor Router**.

## Features

- **Integrated AI Assistant**: Real-time code completions, chat assistance, and workspace refactoring.
- **Dardcor Router Architecture**: Seamless unified access to multiple AI providers (OpenAI, Anthropic, Gemini, DeepSeek, Ollama, and local models).
- **Extensible & Lightweight**: Optimized runtime with minimal overhead and rapid startup.
- **Multilingual Support**: Fully localized interface in 35 languages.
- **Model Context Protocol (MCP)**: Native integration for tools, resources, and custom agents.

## Getting Started

1. Launch Dardcor Code.
2. Configure your AI model preferences via the status bar or settings.
3. Open a folder or repository and start coding.
