# Dardcor Code - Changelog

## 1.0.0 (2026-10-09)

Initial release of Dardcor Code:
- High-performance AI assistant integration with Dardcor Router.
- Native multi-provider support: OpenAI, Anthropic, Gemini, DeepSeek, Ollama, and custom endpoints.
- Lightweight, streamlined core editor architecture.
- Integrated terminal, workspace agent tools, and MCP server support.
- Fully localized interface supporting 35 languages.
