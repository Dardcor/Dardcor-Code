# Dardcor Gemini Web Sync Extension

Ekstensi resmi Chrome/Edge untuk sinkronisasi otomatis akun Google Gemini (`gemini.google.com`) ke Dardcor Router.

## Cara Pasang (10 Detik)
1. Buka Chrome atau Edge, ketik di URL bar: `chrome://extensions` (atau `edge://extensions`)
2. Aktifkan **Developer mode** di pojok kanan atas.
3. Klik tombol **Load unpacked** (Muat yang belum dibongkar).
4. Pilih folder ini:
   `c:\Users\Dardcor\Documents\Code Editor\Dardcor-Code\.dardcor-router\extensions\gemini-web-sync`
5. Ekstensi langsung terpasang!

## Cara Pakai
1. Buka tab `https://gemini.google.com/app` dan pastikan sudah login dengan akun Google Anda.
2. Klik ikon ekstensi **Gemini Web Sync** di toolbar browser Anda.
3. Klik tombol **⚡ Sync Akun ke Router**.
4. Selesai! Akun langsung terhubung ke router secara otomatis tanpa perlu membuka DevTools.
